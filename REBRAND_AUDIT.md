# Rebrand audit — čārana → GOPLAZA

Date: 2026-08-18 · Branch: `rebrand/goplaza` · Base: `7ae610b`

Method: case-insensitive search for `charana`, `čārana`, `چارانا`, `charana.ca`,
`charana://`, `ca.charana.app`, plus filename search for logo/icon/favicon/og/
splash assets, plus a read of every hit to classify **how** it is used.
`node_modules`, `.next`, `.expo`, `.turbo`, lockfiles and the untracked
`apps/mobile/ios` (gitignored, regenerated by prebuild) were excluded.

**Totals:** 178 tracked files · ~430 lines outside `docs/` · 121 lines inside `docs/`.

Risk key — LOW: display text, safe to change. MEDIUM: touches a URL, config
or public identifier; needs a matching external step. HIGH: renaming would
create a new app identity, break sessions, break mail, or rewrite history.

---
