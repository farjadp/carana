# Rebrand plan — čārana → GOPLAZA

Companion to `REBRAND_AUDIT.md`. Branch `rebrand/goplaza`.

## Decisions taken (revisit only with Farjad)

- **D1 — Persian prose form.** The logotype, titles, metadata and every Latin
  context show `GOPLAZA`. Inside Persian sentences the brand is written
  `گوپلازا` — the way `چارانا` stood in for `čārana` — because a Latin
  all-caps token in every RTL sentence breaks the reading line. Both forms
  come from one constant (`brand.name`, `brand.nameFa`); changing the Persian
  form is one edit.
- **D2 — Tagline.** `Discover. Connect. Grow.` / `کشف کن. وصل شو. رشد کن.`
  replaces `Find with confidence.` / `با اطمینان پیدا کن.`
- **D3 — Primary colour.** `--annabi` moves from `#800000` to the brand board's
  burgundy `#7A1831`. Navy, cream, Persian blue and gold already match the
  board and stay. Token *names* (`annabi`, `lajvard`, `gold`) stay — renaming
  ~600 class references is churn with no user value.
- **D4 — Mark.** No vector master was supplied; the only artwork is a raster
  board. The G-mark is rebuilt as clean geometry from that board (a traced
  reproduction, not an invented logo) and labelled provisional in the code
  and in `REBRAND_COMPLETE.md`. When the master SVG arrives it replaces one
  path in two files and the icon PNGs are regenerated by one script.
- **D5 — Workspace packages** are renamed `@goplaza/*`: private, unpublished,
  purely mechanical, verified by typecheck + build.
- **D6 — Nothing that identifies the *installed* app or *live* data changes**:
  bundle id, Android package, EAS slug/projectId, `charana://` scheme (kept
  as secondary), `imports@charana.ca`, Stripe metadata keys, mailbox
  addresses (until Resend verifies `goplaza.ca`).

## SAFE AUTOMATIC CHANGES

1. Central config: `packages/core/src/brand.ts` (name, nameFa, domain, url,
   tagline, colours, `emailDisplayName`), re-exported from `@goplaza/core`;
   `apps/web/lib/data/company.ts` reads brand from it.
2. Every prose/UI/metadata string in §1, §3 of the audit.
3. `--annabi` and hard-coded `#800000` → `#7A1831`; mobile `theme.ts` likewise
   (`annabiDeep`, `softAnnabi` recomputed). `themeColor`/`theme_color`.
4. `apps/web/lib/email/templates.ts` URLs → `brand.url`; mobile `WEB`
   fallbacks → `brand.url`.
5. Workspace package rename + imports + `transpilePackages` + turbo filters,
   then `pnpm install --offline` to refresh the lockfile.
6. New assets under `apps/web/public/brand/goplaza-*` and regenerated
   favicons/app icons; `/story` and `/about` copy rewritten for GOPLAZA;
   old `charana-*` brand files deleted once `grep` shows zero references.
7. Mobile display name, mic permission, scheme array, applinks additions.
8. `.env.example`, `README`, `ARCHITECTURE`, `DEPLOYMENT`, `CLAUDE.md`, `docs/`.
9. `scripts/check-brand.mjs` + `pnpm check:brand`.

## REQUIRES CARE

- `emailRedirectTo: goplaza://auth/confirmed` — only works once the Supabase
  Redirect URLs allow-list contains `goplaza://**`. Ships in code; flagged as a
  before-deploy external action.
- New migration `supabase/migrations/<ts>_rebrand_goplaza.sql` updating the
  blog category display rows and the `author_name` default. Data-only, idempotent.
- `charana:verified` → `goplaza:verified` in JSON-LD (public but non-contractual).
- Vercel: `NEXT_PUBLIC_BASE_URL`, `EMAIL_FROM`, domains, and check the project
  build command does not pin `--filter=@charana/web`.

## DO NOT CHANGE WITHOUT CONFIRMATION

- `ca.charana.app`, EAS slug/projectId — new app identity.
- `imports@charana.ca` — ownership-model identity in production data.
- Stripe `charana_plan` metadata — product lookup key.
- Historical migrations.
- Mailbox addresses `*@charana.ca` — until `goplaza.ca` is a verified sending
  domain and the mailboxes exist.
- Removing `charana://` scheme support — only after old installs are gone.
